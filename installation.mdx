# Installation

Use this page when the [Quick Start](/quickstart) prerequisite check fails or when you need more control over the install path and launch behavior.

## Requirements

The current package requires **Python 3.11+**. The bootstrap installer also requires `git` and Python `venv` support. `whiptail` is optional but recommended for the menu UI.

Check the environment:

```bash
python3 --version
python3 -c 'import venv; print("venv: OK")'
git --version
```

<Warning>
If `python3` is older than 3.11, install a supported Python runtime for your Linux distribution before running DSP. The bootstrap installer intentionally stops instead of creating a virtual environment with an older Python version.
</Warning>

On Debian/Ubuntu systems where the default `python3` is already 3.11 or newer, the usual packages are:

```bash
sudo apt update
sudo apt install -y git python3 python3-venv whiptail
```

## Recommended public install

The current bootstrap script honors `DSP_REPO_DIR`. Set it explicitly so the installation is independent of the script's legacy lab default path:

```bash
export DSP_REPO_DIR="$HOME/xdr-poc-script"
curl -fsSL https://raw.githubusercontent.com/xdr-labs/xdr-poc-script/release/v1.4.0-rc/install-dsp.sh | bash
```

The installer:

1. verifies `git` and a Python 3.11+ runtime with `venv`
2. preserves `~/.dsp/config.env` and existing runs
3. clones or updates the current operator branch
4. creates or reuses `.venv`
5. installs DSP with `pip install -e .`
6. launches `dsp-menu.sh`

## Install without opening the menu

```bash
export DSP_REPO_DIR="$HOME/xdr-poc-script"
export DSP_NO_LAUNCH=1
curl -fsSL https://raw.githubusercontent.com/xdr-labs/xdr-poc-script/release/v1.4.0-rc/install-dsp.sh | bash
```

Launch the menu later with:

```bash
$HOME/xdr-poc-script/dsp-menu.sh
```

## Update an existing installation

The simplest update method is **1 — Update latest patch** in the operator menu.

You can also rerun the bootstrap installer with the same `DSP_REPO_DIR`:

```bash
export DSP_REPO_DIR="$HOME/xdr-poc-script"
curl -fsSL https://raw.githubusercontent.com/xdr-labs/xdr-poc-script/release/v1.4.0-rc/install-dsp.sh | bash
```

<Warning>
The current product scripts use `release/v1.4.0-rc`. The older `release/v1.4.0` branch is explicitly rejected by the installer/menu because it contains retired traffic-volume behavior.
</Warning>

## Verify the installation

```bash
cd "$HOME/xdr-poc-script"
source .venv/bin/activate

dsp --version
dsp plugins list
```

Expected product version is `dsp 1.4.0` on the current operator branch.

## Important paths

| Path | Purpose |
| --- | --- |
| `~/.dsp/config.env` | Persistent operator configuration |
| `~/.dsp/runs/` | Per-run artifacts |
| `$HOME/xdr-poc-script/.venv/` | Python virtual environment when using the recommended path |
| `$HOME/xdr-poc-script/dsp-menu.sh` | Operator menu |
