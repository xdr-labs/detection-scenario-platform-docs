# Installation

## Requirements

DSP requires Python 3.11+ and a small set of standard system tools.

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip whiptail
```

`whiptail` is optional. If it is not installed, the operator menu falls back to a plain numbered prompt.

## Recommended one-command install

```bash
curl -fsSL https://raw.githubusercontent.com/xdr-labs/xdr-poc-script/release/v1.4.0-rc/install-dsp.sh | bash
```

The bootstrap script:

1. Checks `git`, `python3`, Python `venv`, and `pip`/`ensurepip`.
2. Ensures `~/.dsp/` exists without overwriting an existing `~/.dsp/config.env`.
3. Clones or updates the operator release branch.
4. Creates `.venv` if needed.
5. Installs DSP with `pip install -e .`.
6. Makes `dsp-menu.sh` executable.
7. Opens the menu unless `DSP_NO_LAUNCH=1` is set.

Run artifacts under `~/.dsp/runs/` are not deleted by the installer.

## Install without opening the menu

```bash
DSP_NO_LAUNCH=1 bash install-dsp.sh
```

This is useful for automation, smoke tests, or a controlled install workflow.

## Custom install directory

```bash
DSP_REPO_DIR=/opt/xdr-poc-script bash install-dsp.sh
```

The source installer currently defaults to `/home/aella/xdr-poc-script` when `DSP_REPO_DIR` is not specified.

## Update an existing installation

You can rerun the same bootstrap command. The installer is designed to be idempotent:

```bash
curl -fsSL https://raw.githubusercontent.com/xdr-labs/xdr-poc-script/release/v1.4.0-rc/install-dsp.sh | bash
```

Or choose **Update latest patch** from the operator menu.

<Warning>
Do not force the menu to use the retired `release/v1.4.0` branch. The current menu explicitly rejects that branch and points operators to `release/v1.4.0-rc` because the retired branch contains stale traffic-volume behavior.
</Warning>

## Verify the installation

```bash
cd /path/to/xdr-poc-script
source .venv/bin/activate

dsp --version
dsp plugins list
```

The package exposes two console entry points:

- `dsp` — primary operator CLI
- `dsp-remote-scenario` — remote scenario runner used by the webshell execution path

## Important paths

| Path | Purpose |
| --- | --- |
| `~/.dsp/config.env` | Operator configuration |
| `~/.dsp/runs/` | Per-run artifacts |
| `<repo>/.venv/` | Python virtual environment |
| `<repo>/dsp-menu.sh` | Operator menu |
