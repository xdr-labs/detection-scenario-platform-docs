# Validation 상태

현재 릴리스 문서에서 DSP v1.4.0은 다음 상태로 설명됩니다.

**READY WITH KNOWN LIMITATIONS**

## Release Scope 상태

| Capability | 상태 |
| --- | --- |
| Local Execution Provider | Validated |
| JSP를 통한 원격 명령 실행 | Validated |
| PHP를 통한 원격 명령 실행 | Validated |
| JSP/PHP Remote Artifact Upload/Download | Validated |
| Remote Scenario Runner | JSP/PHP Validated |
| Remote Event Collection | JSP/PHP Validated |
| Evidence Export | JSP/PHP Validated |
| Manual Verification Package | JSP/PHP Validated |
| ASPX / Windows IIS Webshell Runtime | **Not validated — Preview** |

## Runtime Platform

| Platform | 상태 | 검증 범위 |
| --- | --- | --- |
| Linux | **Validated** | Local Provider 및 실제 JSP/Tomcat, PHP/Apache Webshell Path |
| Windows | **Not yet validated** | ASPX/IIS 실제 실행 경로는 아직 검증 대기 |

## Webshell Family

### JSP — Validated

실제 Tomcat + `shell.jsp` 환경에서 `host_behavior_check`를 포함한 릴리스 시나리오 전체 검증이 완료되었습니다.

### PHP — Validated

실제 Apache + PHP + `shell.php` 환경에서 `host_behavior_check`를 포함한 릴리스 시나리오 전체 검증이 완료되었습니다.

### ASPX — Preview

Webshell 인터페이스와 HTTP 전송 기능은 구현되어 있지만 현재 릴리스 문서에서는 실제 Windows IIS 실행이 아직 검증되지 않았다고 명시합니다. 현재 검증된 경로에서 원격 번들 실행, 수집, 작업 파일 처리, 플랫폼 분기는 현재 Linux 중심으로 검증되어 있습니다.

<Warning>
실제 Windows IIS 검증이 완료되기 전까지 고객용 자료에서 ASPX/Windows Webshell을 검증 완료 기능으로 표현하지 마십시오.
</Warning>

## Validation이 증명하는 것과 증명하지 않는 것

DSP 릴리스 검증은 **DSP 실행 과정**을 확인합니다.

1. Scenario Activity를 Dispatch할 수 있습니다.
2. Event가 기록되거나 수집됩니다.
3. 이벤트 번들이 로컬 Event Store에 저장됩니다.
4. Validation/Reporting이 실행됩니다.
5. 검증 자료와 수동 확인 템플릿이 생성됩니다.

이 Validation은 특정 외부 보안 제품이 Alert을 발생시켰는지, 특정 Severity를 부여했는지 또는 Signal을 Case로 연결했는지를 자동으로 증명하지 않습니다.

## Release Scope Criteria

Release 1.0 Summary는 실제 JSP/PHP Validation을 통해 다음 네 가지 핵심 기준가 충족되었다고 정의합니다.

- Remote Execution 동작
- Event Bundle 수집
- Evidence Package Export
- Manual Verification Workflow 사용 가능

## 현재 Operator Branch

Installation 및 Menu Script는 다음 Branch를 사용합니다.

```text
release/v1.4.0-rc
```

이전 `release/v1.4.0` Branch는 이전 트래픽 양 동작 때문에 현재 운영 메뉴에서 사용 중단 상태로 처리됩니다.

## 확인 명령

설치된 호스트에서 다음을 실행합니다.

```bash
dsp --version
dsp plugins list
```

고객 테스트 전에 운영 메뉴의 **Show version/status**를 사용하면 현재 Git Branch/Commit, DSP Version 및 Active Configuration을 확인할 수 있습니다.
