# Release Notes

## v1.4.0 — Release 1.0 Readiness

DSP v1.4.0은 **READY WITH KNOWN LIMITATIONS** 상태로 문서화되어 있습니다.

### 주요 Milestone

실제 환경의 원격 실행 검증이 다음 항목에 대해 완료되었습니다.

- JSP / Tomcat
- PHP / Apache
- Remote Command Execution
- Remote Artifact Upload/Download
- Remote Scenario Runner
- Remote Event Collection
- Evidence Export
- Manual Verification Package

ASPX/Windows IIS는 실제 Windows 런타임 검증이 완료되지 않았기 때문에 Preview 상태입니다.

### 현재 Operator 브랜치

현재 Bootstrap Installer와 Operator Menu는 다음 브랜치를 사용합니다.

```text
release/v1.4.0-rc
```

소스 메뉴는 이전 `release/v1.4.0` 브랜치에 이전 트래픽 양 동작이 포함되어 있기 때문에 해당 브랜치를 명시적으로 Retired 상태로 처리합니다.

## v1.3.0 — Operator CLI 단순화

v1.3.0에서는 DSP가 저수준 시나리오 실행 도구에서 보다 운영자 중심의 도구으로 변경되었습니다. 일반적인 사용 절차는 다음 세 가지 결정으로 단순화되었습니다.

1. 어디에서 실행할 것인가 — local 또는 Webshell
2. 어떤 네트워크를 대상으로 할 것인가 — `--target-net`
3. 어떤 실행 프로필을 사용할 것인가

표준 CLI에 진행 상황 표시와 실행 요약도 추가되었습니다.

### Profile 변화

초기 v1.3.0 Documentation은 `low`, `normal`, `high`를 설명했지만 현재 v1.4.0에서는 `low`가 독립 프로필에서 제거되었습니다.

```text
low      → normal
balanced → normal
burst    → high
```

새 Documentation 및 POC Procedure에서는 `normal`과 `high`만 사용해야 합니다.

## v1.2.0 — Webshell 실행 경로

v1.2.0은 표준 `dsp run`에 Webshell 실행 경로를 추가했습니다.

- `--execution-provider webshell`
- `--webshell-family`
- `--webshell-url`
- `--remote-work-dir`
- `--verify-tls`

또한 원격 시나리오 실행과 원격 `events.jsonl` 번들의 자동 수집/가져오기 기능이 추가되었습니다.

## 현재 Documentation 기준

이전 Design Document와 현재 Operator 브랜치의 내용이 충돌하는 경우 이 사이트는 **현재 `release/v1.4.0-rc` 코드와 릴리스 검증 문서**를 기준으로 합니다.

특히 다음 항목은 현재 구현을 기준으로 확인해야 합니다.

- Profile 이름 (`normal` / `high`)
- Scenario 순서
- 현재 Traffic Volume 의미
- Retired된 v1.4.0 브랜치
- ASPX Validation 상태
