# 설정 및 Profile

DSP Operator Menu는 지속적으로 사용할 설정을 다음 파일에 저장합니다.

```text
~/.dsp/config.env
```

일반적인 설정 예시는 다음과 같습니다.

```bash
DSP_REPO_DIR=/home/aella/xdr-poc-script
TARGET_NET=10.10.10.0/24
EXECUTION_MODE=local
PROFILE=normal
WEBSHELL_FAMILY=jsp
WEBSHELL_URL=http://10.10.10.50:8080/shell.jsp
REMOTE_WORK_DIR=/tmp/dsp
```

## 주요 설정

| 설정 | 지원 값 | 설명 |
| --- | --- | --- |
| `TARGET_NET` | CIDR | 필수 Test Scope, 예: `10.10.10.0/24` |
| `EXECUTION_MODE` | `local`, `webshell` | Scenario Activity가 발생하는 위치 |
| `PROFILE` | `normal`, `high` | Target Coverage를 제어 |
| `WEBSHELL_FAMILY` | `jsp`, `php`, `aspx` | Webshell Mode에서만 사용 |
| `WEBSHELL_URL` | HTTP(S) URL | 승인된 Shell Endpoint를 지정해야 함 |
| `REMOTE_WORK_DIR` | 쓰기 가능한 Remote Path | Linux 검증 기본값: `/tmp/dsp` |

## Operational Profile

현재 v1.4.0 Code는 두 개의 Profile을 지원합니다.

| Profile | Scenario Set | Target Coverage | 대상별 Volume |
| --- | --- | --- | --- |
| `normal` | 전체 Active Operational Scenario 순서 | 대표 대상, 일반적으로 최대 2개 | Standard |
| `high` | 동일한 Scenario Set | Guardrail 범위 내에서 발견된 모든 대상으로 확장 | **normal과 동일** |

<Note>
`high`는 대상별 공격 강도를 높이는 Profile이 아니라 **Coverage Expansion**입니다. 현재 Traffic Template은 대상별 Volume을 `normal`과 동일하게 유지하도록 설계되어 있습니다.
</Note>

### 이전 Profile 이름

Runtime은 호환성을 위해 이전 이름을 다음과 같이 처리합니다.

| 이전 값 | 현재 동작 |
| --- | --- |
| `low` | `normal`로 매핑 |
| `balanced` | `normal`로 매핑 |
| `burst` | `high`로 매핑 |

Operator Menu에는 `normal`과 `high`만 표시됩니다.

## 현재 Scenario 실행 순서

Profile 기반 Run은 Discovery-first 순서를 사용합니다.

```text
host_behavior_check
port_sweep
http_followup
sql_injection
ssh_failure
ldap_enumeration
smb_login_failure
kerberos_failure
dga
rare_protocol_activity
dns_tunnel
```

Inactive Plugin은 Runtime에서 제외됩니다. Webshell Mode에서는 사용 가능한 경우 `host_behavior_check`가 필수 1단계 Host Activity로 앞에 삽입됩니다.

## 대규모 Target Guardrail

`/24`보다 큰 Target Network는 두 개의 명시적인 Override를 모두 제공하지 않으면 차단됩니다.

```bash
dsp run \
  --target-net 10.0.0.0/16 \
  --profile high \
  --allow-large-target \
  --max-hosts 10
```

대규모 Network Scope에서는 `--allow-large-target`과 `--max-hosts`가 모두 필요합니다.

## Advanced Scenario 직접 선택

일반적으로 Profile이 Scenario Set을 자동으로 선택합니다. Advanced User는 실행할 Scenario를 직접 지정할 수 있습니다.

```bash
dsp run \
  --scenarios dns_tunnel,http_followup \
  --profile normal \
  --target-net 10.10.10.0/24
```

`--scenarios`를 지정하면 해당 목록이 우선합니다. 동시에 Profile을 지정하면 선택된 Scenario에 Volume 및 Host Limit 설정이 적용됩니다.
