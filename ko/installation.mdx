# 설치

## 요구사항

DSP는 Python 3.11+와 몇 가지 표준 시스템 도구가 필요합니다.

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip whiptail
```

`whiptail`은 선택 사항입니다. 설치되어 있지 않으면 Operator Menu가 일반 번호 선택형 Terminal Interface로 동작합니다.

## 권장 One-Command 설치

```bash
curl -fsSL https://raw.githubusercontent.com/xdr-labs/xdr-poc-script/release/v1.4.0-rc/install-dsp.sh | bash
```

Bootstrap Script는 다음 작업을 수행합니다.

1. `git`, `python3`, Python `venv`, `pip`/`ensurepip`을 확인합니다.
2. 기존 `~/.dsp/config.env`를 덮어쓰지 않고 `~/.dsp/`가 존재하도록 준비합니다.
3. Operator Release Branch를 Clone 또는 Update합니다.
4. 필요한 경우 `.venv`를 생성합니다.
5. `pip install -e .`로 DSP를 설치합니다.
6. `dsp-menu.sh`에 실행 권한을 설정합니다.
7. `DSP_NO_LAUNCH=1`이 아닌 경우 Menu를 엽니다.

Installer는 `~/.dsp/runs/` 아래의 기존 Run Artifact를 삭제하지 않습니다.

## Menu를 열지 않고 설치

```bash
DSP_NO_LAUNCH=1 bash install-dsp.sh
```

Automation, Smoke Test 또는 통제된 설치 절차에서 유용합니다.

## 설치 디렉터리 변경

```bash
DSP_REPO_DIR=/opt/xdr-poc-script bash install-dsp.sh
```

현재 Source Installer에서 `DSP_REPO_DIR`을 지정하지 않으면 기본값은 `/home/aella/xdr-poc-script`입니다.

## 기존 설치 업데이트

동일한 Bootstrap Command를 다시 실행할 수 있습니다. Installer는 반복 실행이 가능하도록 설계되어 있습니다.

```bash
curl -fsSL https://raw.githubusercontent.com/xdr-labs/xdr-poc-script/release/v1.4.0-rc/install-dsp.sh | bash
```

또는 Operator Menu에서 **Update latest patch**를 선택합니다.

<Warning>
Retired 상태인 `release/v1.4.0` Branch를 강제로 사용하지 마십시오. 현재 Menu는 해당 Branch에 오래된 Traffic Volume 동작이 포함되어 있기 때문에 이를 명시적으로 거부하고 `release/v1.4.0-rc` 사용을 안내합니다.
</Warning>

## 설치 확인

```bash
cd /path/to/xdr-poc-script
source .venv/bin/activate

dsp --version
dsp plugins list
```

Package는 두 개의 Console Entry Point를 제공합니다.

- `dsp` — 기본 Operator CLI
- `dsp-remote-scenario` — Webshell Execution Path에서 사용하는 Remote Scenario Runner

## 주요 경로

| 경로 | 용도 |
| --- | --- |
| `~/.dsp/config.env` | Operator Configuration |
| `~/.dsp/runs/` | Run별 Artifact |
| `<repo>/.venv/` | Python Virtual Environment |
| `<repo>/dsp-menu.sh` | Operator Menu |
