# 빠른 시작

## 1. DSP 설치

Debian/Ubuntu 계열 Operator Host에서 다음을 실행합니다.

```bash
sudo apt update
sudo apt install -y git python3 python3-venv python3-pip whiptail

curl -fsSL https://raw.githubusercontent.com/xdr-labs/xdr-poc-script/release/v1.4.0-rc/install-dsp.sh | bash
```

Installer는 현재 Operator Branch를 Clone 또는 Update하고 `.venv`를 생성한 뒤 DSP를 설치하고 Operator Menu를 엽니다. `~/.dsp/` 아래의 기존 Configuration과 Run Artifact는 유지됩니다.

<Warning>
현재 제품 Script가 참조하는 Operator Branch는 `release/v1.4.0-rc`입니다. 이전 `release/v1.4.0` Branch는 Operator Menu에서 명시적으로 Retired 상태로 처리됩니다.
</Warning>

## 2. 환경 설정

Menu에서 **Configure environment**를 선택하고 다음 값을 입력합니다.

| 설정 | 예시 | 의미 |
| --- | --- | --- |
| Target network | `10.10.10.0/24` | DSP 테스트가 허용된 CIDR |
| Execution mode | `local` | DSP Host에서 직접 실행 |
| Profile | `normal` | 대표 대상 범위에 실행 |
| Webshell family | `jsp` | Webshell Mode에서만 사용 |
| Webshell URL | `http://10.10.10.50:8080/shell.jsp` | Remote Shell Endpoint |
| Remote work directory | `/tmp/dsp` | Remote Host의 쓰기 가능한 경로 |

설정은 `~/.dsp/config.env`에 저장됩니다.

## 3. 실행

Menu에서 **Run scenario**를 선택합니다. Menu는 Advanced Operator가 사용하는 표준 CLI와 동일한 실행 경로를 사용합니다.

```bash
dsp run --profile normal --target-net 10.10.10.0/24
```

검증된 JSP Webshell 실행 예시는 다음과 같습니다.

```bash
dsp run \
  --profile normal \
  --target-net 10.10.10.0/24 \
  --execution-provider webshell \
  --webshell-family jsp \
  --webshell-url http://10.10.10.50:8080/shell.jsp \
  --remote-work-dir /tmp/dsp
```

## 4. Evidence 확인

실행 후 다음 디렉터리를 확인합니다.

```text
~/.dsp/runs/<run_id>/
```

주요 Artifact는 다음과 같습니다.

- `events.db` — Run별 Append-only Event Store
- `events.jsonl` — Event Export 및 Remote Bundle 형식
- `traffic_summary.json` — 생성된 활동 Counter
- `validation.json` — DSP Execution Validation 결과
- `report.md` / `report.json` — Run Report
- `verification_checklist.md` — 사람의 검증을 위한 Checklist
- `investigation_notes.md` — Analyst Note Template
- `evidence_summary_template.md` — 고객용 Evidence Summary Template

<Note>
DSP Run이 성공했다는 것은 Activity 및 Evidence Pipeline이 정상 동작했다는 의미입니다. 그 자체로 특정 XDR/NDR Detection이나 Alert이 발생했다는 것을 증명하지는 않습니다. Detection 및 Case Correlation은 보안 플랫폼 UI에서 별도로 확인해야 합니다.
</Note>
